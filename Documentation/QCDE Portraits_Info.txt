"QC: Doom Edition" LegendBourne HD Portrait Pack

This is a 100% optional addon. You can load it in your side for
single player or multiplayer, whether the server has it loaded
or not.

All portraits drawn from scratch by the talented LegendBourne.


====================================================================

* How to use it? *

Make sure you load it after the QCDE files. For example

c:\games\q-zandronum\q-zandronum.exe -file QCDEv3.0.pk3 QCDE--HDfaces3.0.pk3


Or you can just drag and drop it into any of the .bat files included in 
the main QCDE package
