====================================================================

"QC: Doom Edition" Soundtrack

All music performed, mixed, and mastered by Michael Markie

====================================================================

This is a music pack that complements QC: Doom Edition, run it along
with the official mapsets (AeonQCDE or QCDEmaps) for the best
experience.

You can also run this along any mapset and music will be randomized
for each level.

====================================================================

Music in this file has been formatted for looping in GZDoom/Zandronum
For proper beginning-end songs, download the soundtrack in various formats
for better audio quality on:

https://markiemusic.bandcamp.com/album/qc-de-soundtrack
